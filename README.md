# 🚀 Learning Management System (LMS)

A full-stack Learning Management System (LMS) built with a robust backend and a modern frontend interface, designed to streamline course creation, student enrollment, and lecture management.

## 🛠️ Tech Stack

### **Backend:**
* **Node.js**
* **Express.js**
* **MongoDB & Mongoose**
* **JWT (JSON Web Tokens) & bcrypt** for secure authentication

### **Frontend:**
* **Next.js**
* **Tailwind CSS**
* **JavaScript / React**

---

## 🔐 Key Features

* **Authentication System:** Secure User Signup, Login, and Role-Based Access Control (RBAC) using JWT and bcrypt.
* **Course Management:** Dedicated endpoints and dashboards allowing instructors to create, update, and manage courses seamlessly.
* **Enrollment System:** Robust logic enabling students to enroll in courses and track their learning progress.
* **Lesson & Lecture Management:** Authorized content creation enabling instructors to add detailed lessons and video resources to specific courses.
* **Modern UI/UX:** Responsive layouts, dynamic dashboards, and customized dark-themed styling for an optimized user experience.
* **Thoroughly Tested:** RESTful APIs rigorously tested via Thunder Client to ensure clean JSON responses and proper error handling.

## ⚙️ Getting Started & Installation

To run this project locally, follow these steps:

### 1. Clone the Repository

```bash
git clone [https://github.com/Mahnoor-fatima249/LMS.git](https://github.com/Mahnoor-fatima249/LMS.git)
cd LMS

```

### 2. Setup Backend

```bash
cd lms-backend
npm install

```

* Create a `.env` file in the `lms-backend` directory and add your environment variables:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret

```

* Start the backend server:

```bash
npm run dev

```

### 3. Setup Frontend

```bash
cd ../lms-frontend
npm install
npm run dev

```
